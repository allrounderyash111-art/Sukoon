📋 Generated Code

Copy this and paste it into your files on GitHub (see the deployment guide for exactly where).

• The SHAYARIS and PLAYLIST blocks go into script.js, replacing the existing arrays of the same name.
• The Spotify link goes into index.html — find the first link in the top-links block and replace its href.
• The Instagram link goes into index.html — find id="igBtn" and replace its href.
